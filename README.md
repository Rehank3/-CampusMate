# CampusMate

CampusMate is a student assignment management application designed to help students organize assignments, track deadlines, and complete academic work efficiently.

##  Features

-  Create, edit, and manage assignments
-  Track deadlines and remaining days
-  View assignment urgency and priority
-  Upload documents and images for information extraction
-  Get AI-assisted assignment prompts for ChatGPT and Gemini
-  Track assignment completion status
-  Store assignment data using SQLite

##  Technologies Used

- Python
- FastAPI
- Streamlit
- SQLite
- Google Gemini API
- PyMuPDF
- python-docx
